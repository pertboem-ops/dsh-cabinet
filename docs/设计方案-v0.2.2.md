## 一、目标与非目标（v0.2.1 §一 吸收，无改动）

1. **立场连续性**（主卖点）。
2. token 节省（待证假设 → 探针场初证为正，见 §二.2，仍须 n≥3 场复测）。
3. 归档审计器（纪律层机器回读）。

非目标维持：隔离不变量不动、R1 并发形态不动、schema v2 仅增
`replayable`、不引入 agent-team 包、不做人格路径引用、config 不承载
续谈开关。

## 二、核心变更：席位生命周期（吸收 v0.2.1 §二 全文，含 2.4 升档即冷启动、2.5 诚实规则与 replayable、2.6 预算公式）

补充一条探针场新证据入 §二.2 收益清单（V3）：**续谈的第二收益源是
"不重复核验"**——冷启动克隆体重做 R1 已做的文件核验（+~10K uncached），
续谈席位靠会话记忆避免重复劳动。该收益大于简报价差本身，且是立场连续性
的直接副产品。

## 三、前置实证门槛（吸收 v0.2.1 §三 全文：G1/G2/G3′/G5 三口径）

- G1 ✅、G2 ✅（探针级）、G3′ ✅、G5 初测过门（等效成本口径）——
  状态照录 v0.2.1，**不翻转默认 false**。
- 复测任务（入 n≥3 场期）：kimi/zai 路由缓存折扣、缓存 TTL 双时点探针
  （第 1 分钟 vs 超 TTL 后各跑一次 ≤20 字探针，分离折扣率与失活两变量）。
- G4 维持 v0.3 后备，理由按 A3 修正。
